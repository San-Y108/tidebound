# 动态水面与 X 参考接入

2026-11-15。本轮基于现有 v0.2 美术素材继续实现；没有重新生成或覆盖源图。

## 实际接入

- `src/art.js` 将海面、独立木板、七种建筑、船帆、海怪和海盗船打包为内联资源。`src/sea.js` 按船体二维数组逐格绘制精灵，独立格子仍可放置、移动、收回和扩建。
- `src/water.js` 使用生成的 `ocean-v2.webp` 作为纹理，在独立的轻量 WebGL 层上进行小幅双向水面扰动与夕照高光。不是新的 3D 海洋模拟，也没有搬入其他引擎的水面代码。
- 上方遗迹区域降低扰动；海面保持原有画作的色彩与材质，界面与木筏位于水面之上。战斗时环境稍偏冷，亮度变化保持克制。
- 以 30 FPS 和最高 1.25 倍像素比限制背景开销；页面隐藏时不继续绘制，减少动态效果偏好时静止呈现。WebGL 不可用或上下文丢失时回退到原海面背景。
- 所有纹理均进入 `余潮.html`，离线运行不需要从 X、GitHub 或其他外部地址加载素材。

## 参考范围

通过 Agent Reach 的 X `opencli` 后端读取真实推文正文，并通过 GitHub 渠道验证开源仓库及许可证。完整对应关系见 `x-references.md`，证据子集见 `x-reference-evidence.json`。

IsoCity 用来参考独立等距精灵与可交互格子；LesusX、NVJOB、ABYSSAL 和 WaterThreeJS 用来参考水色、浪沫、低成本波纹、日光及船体与水面的接触规律。未下载、复制或重新分发这些项目的美术和 shader。未把未播放的视频元数据声称为观看证据。

## 验证

- `npm test`：14 项规则测试通过，含增益、扩建、战斗、奖励、死亡、七天通关和 500 个种子的确定性。
- 在 `OFFLINE=1`、`GAME_URL=file:///.../余潮.html` 下运行 `npm run test:browser`：实际画布点击、移动、收回、扩建、暂停、刷新续战、商店、精英、Boss、胜利、失败和重新开始通过；没有页面错误。
- 同一离线文件运行 `npm run test:visual`：11 个游戏精灵加载、背景实际绘制非黑像素、时间推进、减少动态效果、360 像素布局与 WebGL 丢失回退通过。
- 画面已在桌面原生尺寸检查，建筑锚点、格子覆盖层和敌人状态面板保持可辨识。

可在开发服务运行时执行：
